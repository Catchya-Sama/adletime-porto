# Brief proyek

## Tujuan
Membuat portofolio pribadi yang memperkenalkan pemilik sebagai video editor dan motion graphic designer, menunjukkan karya editing/VFX/motion graphics, serta memudahkan calon klien menghubungi pemilik.
Workflow: VS Code + Cline, kerja bertahap, preview, Git commit, pencatatan progress, GitHub Pages.

## Arah desain
Referensi https://akiyamanico.github.io/porto dan halaman exhibition-nya.
Pertahankan karakter cream, aksen merah, serif besar/italic, layout lapang, kartu Hire Me seperti tiket, header responsif terhadap arah scroll, halaman Exhibition dengan tab, timeline, footer gelap, dan gerakan halus.
Konten ditulis sendiri sesuai profesi; foto, karya, dan identitas referensi tidak digunakan ulang.

## Ruang lingkup
- Home: Header, Hero, HireCard, StatsCards, bagian menuju Exhibition, Journey, Footer.
- Exhibition: judul, Back to Home, tab About / Skills & Tools / Selected Works.
- Selected Works: daftar karya dan detail terpilih; thumbnail/video, judul, kategori, peran, deskripsi, dan tautan.
- Responsif untuk desktop/tablet/mobile; navigasi keyboard dan reduced motion.
- GitHub Pages dengan HashRouter dan GitHub Actions.
- Tidak membutuhkan backend, database, login, dashboard admin, pembayaran, atau formulir server. Kontak awal melalui email/tautan.

## Data per karya
id unik, judul, kategori, tahun (opsional), peran, deskripsi, thumbnail, alt, videoUrl (opsional), projectUrl (opsional), tools (opsional).
Siapkan 4–6 karya utama. Satu item demo boleh digunakan selama pengembangan dengan penanda 'Contoh / placeholder'; jangan menganggapnya karya pemilik.

## Ukuran keberhasilan
Dua halaman berfungsi, isi profesional sesuai bidang pemilik, layout dekat referensi berdasarkan bukti yang tersedia, animasi tidak menghambat interaksi, mobile tidak overflow, hasil build berhasil, dan tautan publik dapat dibuka serta di-refresh.
