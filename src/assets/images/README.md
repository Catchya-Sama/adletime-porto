# Aset gambar portofolio

Simpan foto profil dan thumbnail karya yang sudah dipilih di folder ini.

Format yang disarankan:

- Foto profil: WebP/JPG, rasio 4:5, minimal 1200 × 1500 px.
- Thumbnail karya: WebP/JPG, rasio 16:9, minimal 1600 × 900 px.
- Usahakan setiap gambar di bawah 1 MB setelah optimasi.
- Gunakan nama file huruf kecil tanpa spasi, misalnya `profile-adle.webp` atau `project-motion-01.webp`.

Karena aset dalam `src` harus di-import oleh Vite, tambahkan import di file data terkait lalu gunakan variabel hasil import sebagai nilai `src` atau `thumbnail`. Lihat `docs/08-content-assets.md` untuk contoh lengkap.
