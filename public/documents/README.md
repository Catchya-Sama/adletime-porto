# Dokumen publik

Folder ini hanya untuk dokumen yang memang aman dipublikasikan, misalnya CV versi publik atau showreel PDF.

Jangan masukkan KTP, dokumen dengan alamat lengkap, nomor telepon pribadi, tanda tangan, data rekening, kredensial, atau informasi rahasia lain.

Gunakan nama file huruf kecil tanpa spasi, misalnya `cv-adle.pdf`. Setelah file tersedia, tambahkan datanya ke `src/data/profile.js` sesuai panduan `docs/08-content-assets.md`.
